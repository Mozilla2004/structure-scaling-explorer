# Structure Scaling Explorer

An interactive visualization tool for exploring structure scaling properties.

## Features

- Interactive visualization of structure scaling
- Real-time parameter adjustments
- Visual feedback and animations

## Usage

Simply open `structure_scaling_explorer_v0.2.1.html` in your web browser.

## Files

- `structure_scaling_explorer_v0.2.1.html` - Main application
- `structure_scaling_v0.2.1.css` - Stylesheet
- `structure_scaling_v0.2.1.js` - JavaScript logic

## Version

Current version: v0.2.1
